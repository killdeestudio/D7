# D-7 재난 생존

> 재난 7일 전. 당신은 무엇을 준비하겠습니까?

카드를 좌우로 넘기며 선택하는 (Reigns 방식) 재난 대비·생존 시뮬레이션입니다.
D-7부터 대비하고, D-Day에 재난을 맞고, 복구되는 날까지 버티면 승리합니다.
게임 끝에는 해당 재난의 **실제 대비 요령**을 보여줍니다.

웹 기술(HTML/CSS/JS)로 만들어 **외부 라이브러리 없이** 어떤 휴대폰 브라우저에서도 돌아가고,
[Capacitor](https://capacitorjs.com/)로 감싸서 **Google Play / App Store 앱**으로 낼 수 있습니다.

## 게임 규칙

- 능력치 4개: ❤️ 건강 · 🧠 정신력 · 🥫 물자 · 🛡️ 안전 — **하나라도 0이 되면 게임 오버**
- 카드를 기울이면 영향을 받는 능력치 위에 점이 뜹니다 (큰 점 = 큰 변화, 오를지 내릴지는 비밀)
- **D-7 ~ D-1 (대비 기간)**: 하루 3장. 돈으로 물건을 사고, 이웃·가족과 관계를 쌓습니다
- **D-Day**: 재난 발생. 준비한 아이템/행동에 따라 피해가 줄어듭니다
- 지진·태풍·대정전은 **결제망이 마비**되어 미리 뽑아둔 **현금만** 쓸 수 있습니다 (D-4에 ATM 카드)
- **재난 이후**: 매일 물자·정신력 등이 소모됩니다. 종료일까지 버티면 생존 (등급 S~C)

#### 북미: 우편번호로 주(州)별 현지화

북미로 시작하면 **ZIP(미국 5자리) 또는 캐나다 우편번호(앞 3자리)** 를 넣습니다. 건너뛰면 캘리포니아 기준입니다.

- **총기 규정이 주마다 다릅니다** (게임용으로 단순화, 2025년 기준 — **확인 필요**, 법이 자주 바뀜):

| 구분 | 주 | 게임 속 효과 |
|---|---|---|
| 대기 기간 | CA 10일, WA 14일(영업일 10일), NM·RI 7일, IL·FL·CO·VT·ME 3일 | D-7에 사면 그만큼 뒤에 수령 |
| 구매 허가증 필요 | HI 14일, MN·NJ·MD·DC 30일, MA·CT 60일, NY 90일 | 대부분 재난이 끝난 뒤에야 받음 |
| 대기 없음 | 그 밖의 주 (예: TX) | 신원조회 후 바로 수령 |
| 캐나다 | 전 지역 | 권총 신규 구매 동결(2022~), 후추 스프레이 불법 → 곰 퇴치 스프레이만 |

- **이 지역 주의**: 재난 선택 화면에서 그 주에 흔한 재난에 표시 (예: CA 지진·산불·폭염, FL 허리케인·폭염).
- ZIP → 주 판정은 앞 3자리 범위표로 합니다 (`www/js/region.js`). 주소나 우편번호는 이 기기에만 저장되고 어디에도 전송되지 않습니다.

### 그 밖의 기능

- **이어하기**: 진행 중인 게임은 카드 한 장마다 자동 저장됩니다 (☰ 버튼으로 나가도 유지).
- **효과음**: 음원 파일 없이 Web Audio로 합성 (스와이프, 구매, 재난, 하루 경과, 생존·사망). 첫 화면이나 게임 중 🔊 버튼으로 끄고 켭니다.
- **오프라인**: 한 번 열면 인터넷 없이 실행됩니다. 온라인일 때는 항상 최신 버전을 받아옵니다.

### 휴대폰에 설치 (앱스토어 없이)

`www/` 폴더를 HTTPS 정적 호스팅(GitHub Pages, Netlify, Cloudflare Pages 등)에 올리면:

- **iPhone (Safari)**: 공유 버튼 → "홈 화면에 추가"
- **Android (Chrome)**: 메뉴 → "앱 설치" 또는 "홈 화면에 추가"

한 번 열면 오프라인에서도 실행됩니다 (서비스 워커 캐시).


게임 파일을 고친 뒤에는 매번:

```bash
npm run cap:sync
```

- **Android**: `npm run cap:android` → Android Studio에서 빌드 → Google Play Console 업로드 (개발자 등록 $25, 1회)
- **iOS**: `npm run cap:ios` → Xcode에서 빌드 → App Store Connect 업로드 (Mac + Apple Developer $99/년 필요)
- 출시 전 `capacitor.config.json`의 `appId`(`com.example.d7survival`)를 본인 도메인 기반으로 바꾸세요.
- 스토어용 1024px 아이콘: `www/icons/icon-1024.png`

### 한국어 문구를 바꾸거나 카드를 추가했다면

영어 번역 사전은 한국어 원문을 키로 씁니다. 문구를 바꾼 뒤:

```bash
npm run i18n
```

누락된 번역 목록이 나오면 `tools/en-part-*.json`에 추가하고 다시 실행합니다. `npm test`도 누락을 잡아냅니다.

지역마다 달라지는 단어는 직접 쓰지 말고 자리표시자를 씁니다: `{EMS}`(119/911), `{LOCAL}`(구청/카운티), `{STORM}`(태풍/허리케인), `{C:43}`(43℃/109℉) 등. 전체 목록은 `www/js/region.js`. 카드 하나만 지역별로 다르게 하려면 `na: { who, text, L: { t }, R: { t } }`를 붙이고, 한 지역 전용 카드는 `when: { region: ['na'] }`.

### 카드 추가 예시

```js
{ id: 'q_example', who: ['🧑', '이웃'], when: { phase: 'post', sc: ['quake'], job: ['doctor'] },
  text: '카드 본문',
  L: { t: '왼쪽 선택', fx: { mind: -5 } },
  R: { t: '오른쪽 선택', $: -100, add: ['medkit'], fx: { hp: 8 },
       cond: [{ has: 'radio', fx: { hp: 10 }, msg: '라디오가 있으면 이렇게' }] } },
```

현재 밸런스(무작위로 고를 때 생존율): 대부분 0~30%, 생각하고 고르면 대부분 생존. 금융인과 대학생이 가장 어렵습니다.
