# D-7 재난 생존

> 재난 7일 전. 당신은 무엇을 준비하겠습니까?

카드를 좌우로 넘기며 선택하는 (Reigns 방식) 재난 대비·생존 시뮬레이션입니다.
D-7부터 대비하고, D-Day에 재난을 맞고, 복구되는 날까지 버티면 승리합니다.
게임 끝에는 해당 재난의 **실제 대비 요령**을 보여줍니다.

웹 기술(HTML/CSS/JS)로 만들어 **외부 라이브러리 없이** 어떤 휴대폰 브라우저에서도 돌아가고,
[Capacitor](https://capacitorjs.com/)로 감싸서 **Google Play / App Store 앱**으로 낼 수 있습니다.

## 게임 규칙

- 능력치 4개: ❤️ 건강 · 🧠 정신력 · 🥫 물자 · 🛡️ 안전 — **하나라도 0이 되면 게임 오버**
- 카드를 기울이면 영향을 받는 능력치 위에 점이 뜹니다 (큰 점 = 큰 변화, 오를지 내릴지는 비밀)
- **D-7 ~ D-1 (대비 기간)**: 하루 3장. 돈으로 물건을 사고, 이웃·가족과 관계를 쌓습니다
- **D-Day**: 재난 발생. 준비한 아이템/행동에 따라 피해가 줄어듭니다
- 지진·태풍·대정전은 **결제망이 마비**되어 미리 뽑아둔 **현금만** 쓸 수 있습니다 (D-4에 ATM 카드)
- **재난 이후**: 매일 물자·정신력 등이 소모됩니다. 종료일까지 버티면 생존 (등급 S~C)

### 재난과 종료 시점

| 재난 | 종료 | 근거(대략) |
|---|---|---|
| 🌋 대지진 | D+10 | 72시간 골든타임 후 구호 본격화, 1~2주 내 단수·단전 대부분 복구 |
| 🌀 초대형 태풍·홍수 | D+7 | 물이 빠지고 도로가 열리는 데 약 1주 |

| 🦠 신종 감염병 봉쇄 | D+21 | 강한 봉쇄 2~3주 후 단계적 해제 |

재난을 "알 수 없음"으로 고르면 무작위로 정해지고 D-7 뉴스로 알게 됩니다.

## 바로 실행해보기

```bash
npm start
```

브라우저에서 http://localhost:8080 을 엽니다. (Node.js만 있으면 됩니다. 또는 `www/` 폴더를 아무 정적 서버로 열어도 됩니다.)

### 휴대폰에 설치 (앱스토어 없이)

`www/` 폴더를 HTTPS 정적 호스팅(GitHub Pages, Netlify, Cloudflare Pages 등)에 올리면:

- **iPhone (Safari)**: 공유 버튼 → "홈 화면에 추가"
- **Android (Chrome)**: 메뉴 → "앱 설치" 또는 "홈 화면에 추가"

한 번 열면 오프라인에서도 실행됩니다 (서비스 워커 캐시).

## 스토어 앱으로 만들기 (Capacitor)

```bash
npm install
```

```bash
npm run cap:add:android
```

```bash
npm run cap:add:ios
```

게임 파일을 고친 뒤에는 매번:

```bash
npm run cap:sync
```

- **Android**: `npm run cap:android` → Android Studio에서 빌드 → Google Play Console 업로드 (개발자 등록 $25, 1회)
- **iOS**: `npm run cap:ios` → Xcode에서 빌드 → App Store Connect 업로드 (Mac + Apple Developer $99/년 필요)
- 출시 전 `capacitor.config.json`의 `appId`(`com.example.d7survival`)를 본인 도메인 기반으로 바꾸세요.
- 스토어용 1024px 아이콘: `www/icons/icon-1024.png`

## 개발

```bash
npm test          # 엔진 단위 테스트 (데이터 무결성, 규칙)
npm run balance   # 직업×재난별 생존율 시뮬레이션
```

| 파일 | 역할 |
|---|---|
| `www/js/data.js` | 캐릭터, 재난, 아이템, **카드 전부** (카드 추가는 여기만 고치면 됨) |
| `www/js/engine.js` | 규칙 엔진 (화면과 분리, Node에서 테스트) |
| `www/js/ui.js` | 화면, 스와이프, 결과 표시, 기록 저장 |
| `www/css/style.css` | 디자인 |
| `www/sw.js`, `manifest.webmanifest` | 오프라인 실행·홈 화면 설치 |
| `tests/` | 테스트와 밸런스 시뮬레이터 |

### 카드 추가 예시

```js
{ id: 'q_example', who: ['🧑', '이웃'], when: { phase: 'post', sc: ['quake'], job: ['doctor'] },
  text: '카드 본문',
  L: { t: '왼쪽 선택', fx: { mind: -5 } },
  R: { t: '오른쪽 선택', $: -100, add: ['medkit'], fx: { hp: 8 },
       cond: [{ has: 'radio', fx: { hp: 10 }, msg: '라디오가 있으면 이렇게' }] } },
```

현재 밸런스(무작위로 고를 때 생존율): 대부분 0~25%, 생각하고 고르면 대부분 생존. 금융인이 가장 어렵습니다.
